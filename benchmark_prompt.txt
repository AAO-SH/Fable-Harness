# I need a *benchmark* software
## Introduce
I need a benchmark written in Python, with real-time result visualization on a web dashboard, regarding:
Compare agent behavior across 4 workspace conditions using the same prompt for complex implementation planned tasks.

## Goal
Measure whether Fable Harness* (https://github.com/aao-sh/fable-harness) and/or Superpowers* (https://github.com/obra/superpowers) improve an agent’s ability to:
* Implement a large project.
* Understand underspecified tasks.
* Inspect the workspace before acting.
* Avoid hallucinated claims.
* Verify work honestly.
* Record evidence, limits, and errors.

## Conditions
Workspace | Condition | Fable Harness* | Superpowers*
workspace_A | plain-agent | no | no
workspace_B | super-only | no | yes
workspace_C | fable-only | yes | no
workspace_D | fable-super | yes | yes

* Each condition must run the exact same prompt once.
* Claims must be evidence-based.
* Tests may only be claimed as passing if actually run.
* A plan alone is invalid. The benchmark must produce implementation artifacts.

## Metrics
* implementation_score: Quality and usefulness of the implementation.
* verification_score: Quality and honesty of testing/verification evidence.
* elapsed_seconds: Time to finish the run.
* error_count: Observable mistakes or missed constraints.
* hallucination_count: Unsupported claims about files, commands, tests, APIs, or packages.
* repair_iterations: Number of correction loops needed.
* token_usage: How much tokens was used at last.

## Invalid Runs
Mark a run invalid if the agent:
* Writes only a plan.
* Edits benchmark files.
* Reuses code from another workspace.
* Claims tests passed without running them.
* Uses tools or skills that should not exist in that condition.

## Reporting Rule
* Do not publish claims until all four conditions are run with the same prompt, same rules, same scoring method, and comparable evidence.
* Do not delete results or artifacts at the end of the benchmark or each run.

## Dashboard
* Create an interactive web dashboard on localhost.
* Update metric results and charts on the dashboard in real time.
* Collects data only from the results generated by the benchmark.
* Needs a button to clear (delete) the benchmark results.
* Needs a button to clear (delete) artifacts generated in the workspaces.
* Needs an input where the user can send the prompt to be used in the benchmark.

## Important general rule
Do not run the benchmark tests! Your task is to program the software designed to perform these tests.

## Legend
* 'Fable Harness' and 'Superpowers' are skills. 'Fable Harness' alters the agent's behavior, and 'Superpowers' offers a package of useful skills.
